# RC-MINI

The is a compact, remote-controlled car powered by an ESP32-C3 SuperMini and a DRV8833 dual H-bridge motor driver. The chassis uses dual N20 micro metal gear motors 
for differential tank-style steering, powered by a 3.7V 1S LiPo battery. Instead of relying on a dedicated remote transmitter, the ESP32 hosts its own local Wi-Fi 
Access Point and serves an interactive web-based joystick interface, allowing real-time driving control from any smartphone browser. The entire setup is hand-wired 
via high-density point-to-point soldering and mounted on a rigid micro frame.
